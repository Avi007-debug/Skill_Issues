# Travel Platform Features

This document outlines all the features of the AI-powered travel platform for Gen Z travelers, combining booking, AI assistance, and social discovery.

## Feature Overview

| Category       | Feature Number | Feature Name                  | Description |
|----------------|----------------|-------------------------------|-------------|
| Core Features | 1              | User Authentication           | - Signup<br>- Login<br>- User profile |
| Core Features | 2              | Flight Search                 | - Source<br>- Destination<br>- Date<br>- Search flights |
| Core Features | 3              | Flight Listing                | - Airline<br>- Price<br>- Duration<br>- Flight timings |
| Core Features | 4              | Flight Booking                | - Passenger details<br>- Confirm booking |
| Smart Features| 5              | AI Travel Chatbot             | Users can ask:<br>- Cheapest flights<br>- Visa requirements<br>- Baggage info<br>- Destination recommendations<br><br>**Why it matters:** Feels like AI concierge. |
| Smart Features| 6              | Price Alerts                  | Users set alerts for:<br>- Route<br>- Date<br>- Preferred price<br><br>Get notified when prices drop.<br><br>**Why it matters:** Helps users save money by alerting to price drops. |
| Smart Features| 7              | AI Itinerary Generator        | After booking:<br>- Places to visit<br>- Trip duration plan<br>- Budget planning<br>- Activities recommendation |
| Smart Features| 8              | Carbon Footprint Tracker      | Shows:<br>- CO₂ emissions<br>- Eco-friendly flights<br>- Green recommendation |
| Smart Features| 9              | Squad Trip Split              | - Add friends<br>- Split expenses<br>- Shared bookings |
| Vibe Mode     | -              | Vibe Mode Toggle              | Toggle: **Normal Mode ↔ Vibe Mode**<br><br>This is the BIG differentiator - Gen Z Mode for memorable travel discovery. |
| Vibe Mode     | 10             | Swipe Destination Discovery   | Like Tinder for travel<br><br>- Swipe right → interested<br>- Swipe left → skip<br><br>System recommends destinations. |
| Vibe Mode     | 11             | Reel-Worthy Destination Score | Shows:<br>- Aesthetic score<br>- Nightlife score<br>- Trending score<br>- Content creation score<br><br>Example:<br>- Goa → 9/10<br>- Bali → 10/10<br><br>Inspired by Instagram/TikTok travel behavior. |
| Vibe Mode     | 12             | Travel Buddy Finder           | Like Bumble for travelers<br><br>Find people with:<br>- Same destination<br>- Same dates<br>- Similar interests<br><br>Perfect for solo travelers.<br><br>**Why it matters:** Connects solo travelers with like-minded companions for safer and more enjoyable trips. |

## Final Product Positioning

This is NOT a "MMT clone". This becomes an **AI-powered travel platform for Gen Z travelers** or a **Travel app that combines booking + AI + social discovery**.

Traditional travel apps → transactional  
Your app → experiential + social + personalized

That's exactly what judges remember. The feature count is high enough to impress, but still manageable with dummy data for demo.
